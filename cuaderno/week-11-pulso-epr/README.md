# Pulso EPR

Pulso EPR is David Buzali's Week 11 Business Bending working slice: an EPR Commercial Viability Comparator for repeated packaging-evidence reconciliation in Mexico.

**Live product:** <https://week-11-pulso-epr.vercel.app>  
**Status:** persona-tested educational prototype  
**Important:** it does not certify compliance, prove recycling, calculate regulatory obligations, or recommend a vendor.

## Dragon Stack

- **IoT / phone sensing:** local timer, reconciliation checkpoints, page-visibility interruptions, and optional motion sample count; simulated fallback is visibly labeled.
- **ML:** deterministic synthetic-trained linear effort range with model version, confidence gate, and visible drivers.
- **Marketplace logic:** constraint-first comparison of spreadsheet, consultant, partner platform, and local adapter routes.

## Data handling

No account, backend, database, analytics, cookies, personal fields, document upload, or third-party runtime request. The optional motion signal is reduced to a local count and is never sent anywhere. Export is an explicit local JSON download containing aggregate values only.
